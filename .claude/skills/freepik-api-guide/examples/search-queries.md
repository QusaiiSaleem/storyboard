## Tips for Better Results

1. **Be specific**: "business meeting in office" vs "business"
2. **Include style**: "flat design illustration" vs "illustration"
3. **Add context**: "mobile app ui" vs "ui"
4. **Use synonyms**: Try "workplace", "office", "corporate"
5. **Combine filters**: type + orientation + license for precision
6. **Start broad, then refine**: Begin with general terms, add filters
